BOOT LOGO PICTURE

Put ONE picture in this folder: .png, .jpg, .jpeg or .bmp.
Then open Apps > Logo on the Brick. Restart the Brick to see it.

- The picture is fitted to the screen and centred on black; it is not stretched
  or cropped. Transparent areas become black.
- If there are several pictures, the newest one is used.
- To get the original TrimUI logo back: empty this folder (this text file can
  stay) and open Logo again.
- The first run saves the Brick's own logo as Slot/BootLogo/original.bmp.
  Keep a copy of that file on your computer; it is the only way back.
- What happened is written to Apps/BootLogo/status.txt.
